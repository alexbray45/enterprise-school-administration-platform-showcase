# 💻 Technology Stack

## Overview

AdminTrack has been designed using a modern, enterprise-oriented technology stack that prioritises maintainability, scalability, performance, and long-term support.

Each technology was selected based on its suitability for building a secure and reliable web-based administration platform.

---

# Technology Overview

| Layer           | Technology             | Purpose                                    |
| --------------- | ---------------------- | ------------------------------------------ |
| Frontend        | React 19               | Build a modern, interactive user interface |
| Backend         | ASP.NET Core 9 Web API | Business logic and RESTful API services    |
| Database        | PostgreSQL             | Relational data storage                    |
| ORM             | Entity Framework Core  | Data access and object-relational mapping  |
| Authentication  | JSON Web Tokens (JWT)  | Secure user authentication                 |
| Styling         | Bootstrap 5            | Responsive user interface design           |
| Version Control | Git & GitHub           | Source control and collaboration           |
| Documentation   | Markdown               | Project documentation                      |

---

# Frontend

## React 19

React was selected to build a responsive and component-based user interface.

### Benefits

- Component-based architecture
- Reusable UI components
- Efficient rendering
- Strong ecosystem
- Excellent developer experience

---

# Backend

## ASP.NET Core 9 Web API

ASP.NET Core provides the backend services that power the application.

### Benefits

- High performance
- Cross-platform support
- Enterprise-grade framework
- Built-in dependency injection
- Excellent security features
- Long-term maintainability

---

# Database

## PostgreSQL

PostgreSQL serves as the primary relational database for the application.

### Benefits

- ACID compliance
- Strong data integrity
- Excellent performance
- Advanced querying capabilities
- Scalability
- Open-source

---

# Data Access

## Entity Framework Core

Entity Framework Core provides an object-relational mapping (ORM) layer between the application and the database.

### Benefits

- Simplified database interaction
- Reduced boilerplate code
- Strong integration with ASP.NET Core
- Migration support
- LINQ querying

---

# Authentication

## JSON Web Tokens (JWT)

JWT is used to authenticate users and protect access to secured resources.

### Benefits

- Stateless authentication
- Secure token-based access
- Suitable for RESTful APIs
- Supports role-based authorisation

> **Note:** Authentication implementation details are intentionally omitted from this public repository.
